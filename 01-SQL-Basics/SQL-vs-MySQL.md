# 🆚 SQL vs MySQL

## 📌 Definition

### SQL

**SQL (Structured Query Language)** is a language used to communicate with and manage relational databases.

### MySQL

**MySQL** is a **Relational Database Management System (RDBMS)** that uses SQL to store, retrieve, and manage data.

---

# 📊 SQL vs MySQL

| SQL                                                    | MySQL                     |
| ------------------------------------------------------ | ------------------------- |
| Language                                               | RDBMS                     |
| Defines how we communicate with databases              | Stores and manages data   |
| Contains commands such as `SELECT`, `INSERT`, `UPDATE` | Executes SQL commands     |
| Not a database system                                  | A database system         |
| Standard language                                      | Specific database product |

---

# 💻 Example

SQL query:

```sql
SELECT *
FROM employees;
```

This is **SQL**.

When this query is executed using MySQL, **MySQL processes the SQL query and returns the result**.

---

# 🎯 Most Asked Interview Questions

### 1. What is the difference between SQL and MySQL?

> SQL is a language used to communicate with relational databases, while MySQL is an RDBMS that uses SQL to store and manage data.

---

### 2. Is MySQL a programming language?

> No. MySQL is a Relational Database Management System (RDBMS).

---

### 3. Is SQL a database?

> No. SQL is a language. A database stores data, while an RDBMS such as MySQL manages that data.

---

### 4. Can we use SQL without MySQL?

> Yes. SQL is a standard language supported by many RDBMSs such as PostgreSQL, Oracle, SQL Server, and MySQL.

---

### 5. Is SQL and MySQL the same?

> No. SQL is a language, whereas MySQL is an RDBMS that uses SQL.

---
