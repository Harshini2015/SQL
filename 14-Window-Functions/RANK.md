# 🥇 RANK() Function

## 📌 Definition

The **`RANK()`** window function assigns a rank to each row within a partition, **leaving gaps in the ranking sequence** when duplicate values (ties) occur.

---

## 🔑 Key Concepts

* **Handles Ties:** Assigns the **same rank number** to rows with identical sorting values.
* **Leaves Gaps:** When ties occur, `RANK()` skips subsequent rank numbers.
* **Sequence Example:** For values `[100, 100, 90, 80]`, `RANK()` returns $\mathbf{1, 1, 3, 4}$ (Rank 2 is skipped!).

---

## 💻 Syntax & Example

```sql
SELECT 
    name, 
    department, 
    salary,
    RANK() OVER(PARTITION BY department ORDER BY salary DESC) AS rnk
FROM employees;
```

## 📝 Example Result

### `employees` Table

| name  | department | salary |

| Rahul | IT         |  80000 |

| Amit  | IT         |  60000 | **3** *(Gap: 2 skipped)* |
| Neha  | IT         |  50000 | **4** |

# 🎯 Most Asked Interview Questions

### 1. Does `RANK()` leave gaps in ranking numbers when ties occur?
> **Yes.** When two or more rows tie for a rank, `RANK()` assigns them the same rank and skips the subsequent rank numbers.

---

### 2. What are the rank numbers generated by `RANK()` for scores `[95, 95, 95, 80]`?
> Ranks will be: $\mathbf{1, 1, 1, 4}$ (Ranks 2 and 3 are skipped).

---

# 🧠 Quick Revision

```text
RANK() OVER(PARTITION BY ... ORDER BY ...)
 ├── Tied values → Same Rank Number
 └── Next distinct value → Leaves Gaps (1, 1, 3, 4)
```

> **Memory Trick:** `RANK = Same rank for ties + LEAVES GAPS`
